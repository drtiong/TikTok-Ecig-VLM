# TikTok-Ecig-VLM
Code, codebook, prompts, and aggregate analysis outputs for validation and deployment of a vision-language model (Gemini 3.1 Pro) for detecting indirect e-cigarette promotion on TikTok.

## Data availability

The raw video dataset analyzed in this study is not publicly available because the videos were collected from TikTok and contain third-party audiovisual content, including potentially identifiable individuals. Redistribution of the original video files may raise privacy, copyright, and platform-governance considerations. In addition, conventional de-identification cannot reliably eliminate the possibility of re-identification from audiovisual content.

To support reproducibility, this repository provides the study's coding framework, operational definitions, model prompts, data-processing procedures, analytical code, and aggregate analysis outputs. These materials allow the analytical workflow and statistical analyses to be examined and reproduced without redistributing the underlying third-party video content.
